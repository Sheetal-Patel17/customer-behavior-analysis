# Customer Shopping Behavior Analysis

## 📊 Overview
This project analyzes customer shopping behavior using Python and PostgreSQL.

## 🛠 Technologies Used
- Python (Pandas)
- PostgreSQL
- SQLAlchemy
- Jupyter Notebook

## 🔗 Database Integration
- Connected Python to PostgreSQL
- Loaded dataset into database table
- Performed SQL queries for analysis

## 📈 Key Insights
- Revenue analysis based on gender
- Customer purchasing patterns

## 🚀 How to Run
1. Install dependencies:
   pip install pandas sqlalchemy psycopg2-binary

2. Open notebook:
   notebook/Customer_Shopping_Behavior_Analysis.ipynb

3. Update database credentials

4. Run all cells

## ⚠️ Note
Database connection is local (localhost), update credentials before running.
